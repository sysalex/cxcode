# 运行手册 Runbook

## 发布规则

- 活跃考试期间不得发布高风险变更。
- 数据库 migration 应尽量向后兼容。
- 高风险行为变更必须使用 Feature Flag。
- 发布前必须知道回滚步骤。

## 回滚检查清单

- 确认发布版本。
- 确认数据库 migration 是否可逆。
- 如有 Feature Flag，先关闭开关。
- 回滚应用版本。
- 验证健康检查。
- 验证考试开始、自动保存、提交、成绩读取路径。
- 检查告警和错误率。

## 故障处理清单

1. 确认受影响的考试、作答和用户。
2. 收集 requestId、traceId 和审计事件。
3. 检查自动保存和提交错误率。
4. 确认答案数据是否已持久化。
5. 冻结不安全发布。
6. 执行缓解措施。
7. 同步已知影响。
8. 故障结束后增加回归测试或质量门禁。

## 高风险故障

- 活跃考试不可用
- 自动保存失败率激增
- 提交失败率激增
- 超时提交错误
- 越权访问答卷或成绩
- 考前泄题
- 审计日志写入失败
