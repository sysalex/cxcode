# 在线考试系统产品规格

## 范围

系统需要支持：

- 用户登录和基于角色的访问控制
- 题库管理
- 考试创建和排期
- 组卷
- 考生在线作答
- 答案自动保存
- 手动交卷
- 超时交卷
- 阅卷
- 成绩发布
- 监考信号记录
- 审计和报表

## 基线版本暂不包含

- 支付能力
- 离线原生客户端
- 无人工复核的 AI 自动主观题评分
- 高风险生物识别身份核验

## 主要角色

- 管理员
- 教师
- 考生
- 监考员
- 审计员

## 核心用户流程

### 考生参加考试

1. 考生登录。
2. 考生打开被分配的考试。
3. 系统校验资格、时间窗口和作答状态。
4. 系统创建或恢复作答。
5. 考生答题。
6. 系统自动保存答案。
7. 考生手动交卷，或系统在超时时交卷。
8. 考生收到提交确认。

### 教师发布成绩

1. 教师查看已提交答卷。
2. 系统计算客观题得分。
3. 教师按需批改主观题。
4. 教师发布成绩。
5. 考生只能查看自己的已发布成绩。

## 关键失败场景

- 考生考试中刷新浏览器。
- 自动保存时网络中断。
- 考生重复提交。
- 手动提交和超时提交同时发生。
- 考生尝试访问其他人的答卷。
- 教师修改已用于正式试卷的试题。
- 活跃考试期间执行数据库迁移。

相关功能完成前，每个失败场景都必须有测试、日志和恢复策略。
