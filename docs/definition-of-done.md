# Definition of Done：任务完成标准

任务只有在相关事项全部完成后才算完成：

- 需求行为已实现。
- 强制 TDD 范围内的改动已先写失败测试，并完成 Red-Green-Refactor。
- 领域不变量未被破坏。
- 状态流转合法。
- API 契约已更新。
- 需要时已添加数据库 migration。
- 权限检查已实现并测试。
- 错误码和异常映射已补齐。
- 结构化日志和审计事件已补齐。
- 单元测试通过。
- 需要时集成测试通过。
- 关键用户路径需要时有 E2E 覆盖。
- 安全敏感行为需要时有安全测试覆盖。
- `scripts/check.ps1` 通过，或存在被允许的临时例外。
- 文档和 ADR 已更新。
- `docs/task-list.md` 已更新。
- `CHANGELOG.md` 已更新。
- 没有新增架构边界违规。

对考试提交和答案持久化相关任务，幂等性、授权、审计日志、数据完整性不允许临时例外。
