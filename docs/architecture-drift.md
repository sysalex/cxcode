# 架构漂移检测

架构漂移是指实现逐渐偏离已记录的架构约束。能机械化检测的漂移必须用工具检测。

## 漂移信号

- 非法依赖方向
- 循环依赖
- 领域层导入框架代码
- UI 直接导入持久化代码
- API 行为未写入契约
- 状态流转绕过状态机
- 敏感操作缺少审计事件
- 领域失败缺少稳定错误码
- 运行日志缺少关联字段

## 必须逐步加入的检查

技术栈确定后，加入：

- import 边界检查
- 循环依赖检查
- 死代码检测
- 重复代码检测
- 未使用导出 API 检测
- API schema 漂移检测
- 数据库 migration 漂移检测
- 文档链接完整性检测

## 响应循环

```text
发现漂移 -> 分类 -> 修正代码或更新 ADR -> 增加回归检查
```

如果文档中的架构已经不合理，必须通过 ADR 更新架构，而不是默默接受漂移。
