# 质量门禁

质量门禁是强制验证步骤。不允许为了完成任务而跳过、削弱或删除。

## 本地门禁

`scripts/check.ps1` 最终必须运行：

```text
格式检查
lint
类型检查
单元测试
架构边界检查
API 契约校验
构建
```

强制 TDD 范围内的任务必须先有失败测试记录，不能只在实现后补“快乐路径”测试。

质量门禁脚本必须在任何子命令失败时以非零退出码结束，不能吞掉 `pnpm`、`mvn` 等外部命令失败。

## CI 门禁

CI 必须运行本地门禁，并增加：

```text
集成测试
关键 E2E 流程
安全检查
依赖漏洞检查
migration 检查
license 检查
覆盖率报告
```

## 发布门禁

生产发布前必须确认：

```text
所有 CI 门禁通过
数据库 migration 已评审
回滚计划已记录
runbook 已更新
可观测 dashboard 可用
告警已配置
未违反活跃考试发布冻结规则
```

## 临时例外

质量门禁例外必须记录：

- 原因
- 负责人
- 过期时间
- 风险评估
- 后续任务

认证、授权、考试提交、答案持久化、成绩发布相关安全要求不得申请临时例外。
