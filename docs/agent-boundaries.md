# Agent 行为边界

本文档定义自动化编码 Agent 在本仓库中可以做什么、不可以做什么。

## 允许

- 阅读项目文档和相关代码。
- 使用 `docs/tasks/TEMPLATE.md` 创建任务计划。
- 按 `ARCHITECTURE.md` 做范围明确的改动。
- 随实现同步增加测试和文档。
- 运行仓库脚本。
- 为重要设计选择提出 ADR。

## 禁止

- 未记录例外就绕过质量门禁。
- 删除测试来让检查通过。
- 削弱安全、授权、幂等、审计要求。
- 在领域代码里引入具体框架依赖。
- 实现 `docs/state-machines.md` 未记录的隐藏状态流转。
- 静默修改不可变领域记录。
- 记录密码、token、答案 key、原始敏感答案内容。

## 需要人工确认

- 认证或授权模型变化
- 破坏性数据库 migration
- 考试提交语义
- 超时行为
- 成绩发布语义
- 安全策略例外
- 生产发布和回滚决策
