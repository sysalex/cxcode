# 任务计划：考试作答 MVP

## 目标

实现第一条可运行闭环：考生查看可参加考试、开始或恢复作答、填写答案、自动保存、手动提交。

## 范围

- 建立 React/Vite 前端和 Java/Spring Boot 后端项目结构。
- 实现领域模型和基础状态流转。
- 实现应用服务和内存仓储端口。
- 实现 Spring Boot API。
- 实现 React/Vite 前端作答页面。
- 接入基础质量门禁。

## 非范围

- 生产数据库。
- 用户登录系统。
- 完整教师后台。
- 主观题阅卷。
- 监考视频能力。
- 部署流水线。

## 影响区域

- 领域：考试、作答、答卷、提交。
- API：考试列表、开始/恢复作答、读取作答、自动保存、提交。
- 数据：第一阶段使用内存 seed 数据。
- UI：考生作答页面。
- 安全：使用固定演示用户，保留后续认证授权入口。
- 可观测：API 结构化日志基础字段。
- 测试：领域测试、应用服务测试、API 冒烟测试。
