# 业务术语表

- 考试 Exam：包含考试规则、时间窗口、参与人和试卷的测评活动。
- 试卷 Paper：分配给某次考试或某次作答的题目集合。
- 试题 Question：题库中可复用的题目。
- 考生 Candidate：参加考试的用户。
- 教师 Teacher：创建、管理或阅卷的用户。
- 监考员 Proctor：监控考试过程的用户或自动化服务。
- 作答 Attempt：考生一次进行中或已完成的考试会话。
- 答卷 Answer Sheet：某次作答中保存的答案。
- 提交 Submission：答卷最终确认。
- 自动保存 Auto-save：考试过程中周期性保存草稿答案。
- 超时提交 Timeout Submit：考试时间到达后触发的最终提交。
- 成绩 Grade：提交后产生的分数和反馈。
- 结果 Result：发布后考生可见的成绩。
- 审计事件 Audit Event：用于安全追踪和问题调查的不可变事件。
- 幂等键 Idempotency Key：用于保证重试安全的请求标识。
