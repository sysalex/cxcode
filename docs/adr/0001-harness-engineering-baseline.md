# ADR-0001：采用 Harness Engineering 基线

## 状态

Accepted

## 背景

在线考试系统对正确性、安全性、可观测性和运行可靠性要求较高。人类开发者和 AI Agent 需要共享一套工程控制系统，用来定义上下文、约束、自动化、验证和反馈循环。

## 决策

采用 Harness Engineering 基线，包括：

- 仓库内事实源文档
- 明确架构边界
- 领域模型和状态机文档
- 强制质量门禁
- 稳定脚本入口
- 结构化日志、审计事件、指标和链路追踪
- Definition of Ready 和 Definition of Done
- 任务计划和 ADR
- 开发、运行故障、架构漂移的反馈循环

## 影响

- 任务需要更多前置结构。
- 行为变化必须同步更新文档和测试。
- 技术栈确定后，质量门禁必须可执行并被 CI 强制执行。
- Agent 有明确边界和可重复执行的命令。
